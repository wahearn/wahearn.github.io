# Category Three: Databases
The main improvement I made to this enhancement was developing improved database integrity. In these changes I have improved the MongoDB connection and timeout settings, connection ping, and graceful shutdown when the program exits. I have also restricted the queries and operators to a safe whitelist to prevent calls that are not required for the animal shelter app to work. Queries have been further sanitized to prevent bad or malformed data being supplied to the database.

I believe this enhancement met the course outcomes I originally planned to address. For category two I wanted to address outcome five. This enhancement demonstrated my ability to develop a security mindset that anticipates adversarial exploits in software architecture and designs to expose potential vulnerabilities, mitigate design flaws, and ensure privacy and enhanced security of data and resources. 

The enhancement process taught me the importance of database design and how queries should be properly handled. When the original project was first created, it used basic CRUD operations with fixed queries that had little to no sanitation performed. Now, data is properly sanitized when constructing a query, the database has a solid connection with graceful timeout and shutdown, and the code has been modularized to separate the database from other critical functions.
