# Professional Self-Assessment

Over the past three years in the Computer Science program, I have developed a much stronger understanding of software development and how the different areas of computer science work together to create complete applications. When I first began the program, I was mainly focused on learning how to write code and make programs function correctly. As I progressed through the program, I learned that software development involves a lot more than just simply writing code. It also requires planning, problem-solving, database management, security, testing, communication, and the ability to improve an application over time. The projects included in this ePortfolio demonstrate the progress I have made in these areas and show how my skills have developed throughout the program. 

One of the most important skills I developed is the ability to design and organize software applications. Throughout my coursework, I learned how to take larger problems and divide them into smaller, more manageable components. This comes into play in the first category: software engineering and design, which helped me understand the importance of modular programming, separation of responsibilities, and writing code that can be maintained and expanded later. Rather than focusing only on whether an application works, I better understand how code should be structured, and how difficult it can be to add new functionality.

I also gained valuable experience working with databases and client/server applications. In my original CS 340 project, it required an application to communicate with a database and perform CRUD operations to create, read, update, and delete information. Developing a basic CRUD application has helped me understand how the different components of software communicate with one another. It also showed me how database design and queries can affect the functionality and performance of an application. Through my capstone enhancements, I was able to build on these skills by improving how the application searches, organizes, and manages its data. 

Secure coding has also become another important part of how I approach software development. During the program, I learned that an application should not only perform its intended functions but should also protect its data and reduce unnecessary security risks. Input validation, error handling, access control, and safe database interaction are all important parts of developing reliable software. It's changed the way I think about programming because security is something that should be considered throughout the development process rather than added after an application has already been completed. My capstone project gave me an opportunity to demonstrate these skills by taking an using the CS 340 project and turning it into a full-stack application, trying all three categories with one artifact. For the software engineering and design enhancement, I focused on improving the application's organization by refactoring the original code into a more modular structure. In the algorithms and data structures enhancement, I focused more closely on how the application categorizes information. I improved the way users can filter and sort animal data so that the application can identify useful candidates more effectively. In the database enhancement, I took the time to further develop the database skills I gained in CS 340. I focused on improving CRUD functionality, query design, data organization, and database security. Because the original project was already based around a client/server application connected to a database, it provided a strong foundation for working on all three of these skills. 

Overall, my capstone project demonstrates that I can work with existing code, improve application architecture, strengthen database functionality, work with data effectively, and identify opportunities to reduce security risks. In my experience the Computer Science program has changed the way I approach software development: I have moved beyond simply trying to make code work and have developed a greater mindset for software design, security, testing, and maintainability. The artifacts and enhancements included in this ePortfolio represent the skills I have built over the past three years and demonstrate my growth as a computer science student. They also provide a foundation that I can continue to build on as I pursue a career in software development and continue learning new technologies and development practices.
